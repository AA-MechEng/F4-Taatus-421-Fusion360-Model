# F4 Race Car Model – Fusion 360

## Overview

This project is a 3D CAD model of a Formula 4 (F4) race car developed using Autodesk Fusion 360. The aim was to improve my CAD modelling skills while recreating key components and proportions of a modern single\-seater racing vehicle.

## Software Used

- Autodesk Fusion 360

## Features

- Full vehicle assembly
- Front and rear wing assemblies
- Chassis and bodywork
- Suspension components
- Wheel and tyre models
- Rendered visualisations

## Files Included

- Fusion 360 source file (.f3d)
- STEP export (.step)
- Project renders and screenshots

## Skills Demonstrated

- 3D CAD modelling
- Assembly design
- Parametric modelling
- Engineering design principles
- Technical visualisation
